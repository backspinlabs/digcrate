Rekordbox playlists in key order

You can put a Rekordbox playlist in key order two ways: sort it inside Rekordbox, or plan the running order first and import it as a Rekordbox XML playlist.

Menu names below follow the Rekordbox 7 manual, version 7.2.18. Other versions may label them differently.

Show keys as codes

Open Preferences > View > Display Type and set Key display format to Alphanumeric. Keys then show as codes like 1A and 2A instead of names like Abm and B. Codes make it quick to spot the moves that mix cleanly; the Camelot wheel guide explains them.

Sort a playlist by key

  1. Open the playlist. Show the Key column if it’s hidden.
  2. Click the Key column heading. Click it again to switch between ascending and descending order.
  3. Keep the order. With the playlist still sorted by key, choose Renumber Track Order from the Playlist menu. Rekordbox renumbers the tracks in the order they’re sorted.
  4. Adjust by hand. Sort by the track number column again, then drag tracks to fine-tune the order.

What a key sort doesn’t do

A key sort groups tracks that share a key. It doesn’t check that the last track in one group mixes with the first track in the next, and it ignores tempo and energy. Treat a sorted playlist as a crate to pick from, not a running order.

Find compatible keys while you play

  • Traffic Light. With the Key column showing, Rekordbox highlights the keys of tracks that are compatible with the track on the selected deck. Set the range of keys it highlights in Preferences > View > Display Type.
  • Track filter. Filter the track list by KEY, and turn on Master Player or Master Deck to use the key of the track that’s playing.
  • Related Tracks. List tracks related to the loaded one by BPM, key, genre, rating, My Tag, and more.

Plan the order first, then import it

For a set where every handoff is checked before the gig, plan the order outside Rekordbox and bring it in as one playlist. With DigCrate on a Mac:

  1. Scan your music folder. DigCrate reads the BPM, key, and energy of every track. Tracks with shaky analysis go to a review queue, where you fix a BPM or key by hand.
  2. Build the set. Describe it in plain English and the planner picks and orders tracks from your library. Every handoff is scored on the harmonic wheel, with a short note on why it works or clashes. Reorder tracks or fill a flagged gap until the order is right.
  3. Export Rekordbox XML. DigCrate writes the set as a Rekordbox XML playlist in set order, with its track metadata.
  4. Point Rekordbox at the file. Open Preferences > Advanced > Database and set Imported Library under rekordbox xml to the exported file.
  5. Show the XML library. If rekordbox xml isn’t in the tree view, open Preferences > View > Layout and check rekordbox xml under Media Browser.
  6. Import the playlist. In the tree view, double-click rekordbox xml, then Playlists. Drag your set under Playlists. Import Playlist in the Playlist menu does the same for a selected playlist.

If you export the set again later, use the update button on the rekordbox xml library to load the latest version.
