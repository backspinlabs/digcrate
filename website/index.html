Download on the Mac App Store

Plan DJ sets that mix in key.

DigCrate reads your local library for BPM, musical key, and energy, then helps you build sets with clean harmonic transitions and export playlists for your DJ software.

Analyze your library on your Mac

Point DigCrate at a folder and it reads the BPM, the musical key in 8A-style harmonic notation, and the energy of every track.

Tracks with shaky analysis are flagged in a review queue. Fix a BPM or key by hand, confirm the rest, and keep your library clean.

Audition any track from a smart cue point near the part that matters, not the silence at the top. Filter by BPM, key, or energy, search by text, and see counts, ranges, and most-common keys for the whole library.

Describe the set, then review the plan

Describe the set in plain English, such as “60-minute liquid roller, mellow start, peak around minute 40,” and the planner picks and orders tracks from your library for flow.

Every handoff is scored on the harmonic wheel, with a short note on why it works or clashes. Listen through the transitions, then reorder tracks or fill a gap before you export.

Find the weak transitions and fill them

Weak transitions are flagged with the BPM, key, and energy of a bridge track that would smooth them over. One click opens Beatport, Spotify, or SoundCloud searches for that profile in your browser.

Export to Rekordbox XML or M3U

The set keeps its track metadata, so you can import it into Rekordbox or other DJ software that reads M3U.

What your Mac needs

DigCrate runs on Apple Silicon with macOS 14 or later. Apple’s on-device language-model planning requires macOS 26 or later with Apple Intelligence enabled and available. A model server you configure is another option; without an available language model, the planner can fall back to rules-based ordering.

A configured model server receives your planning prompt and selected track metadata, so use a server you trust. The current 1.x release does not include Apple Cloud planning. Read the privacy details.

Open-source CLI

The DigCrate CLI on GitHub is a separate Python tool that scans, plans, and exports from the terminal. Its planner uses an OpenAI API key you supply.
